# BoxPlot
- **Props:** Category and five-number summaries, label, size, color and formatter.
- **Dependencies:** Shared responsive chart container.
- **Styling Decisions:** Thin whiskers and low-opacity boxes make medians the strongest mark.
- **Maintenance Notes:** Consumers must provide ordered min ≤ q1 ≤ median ≤ q3 ≤ max values.
